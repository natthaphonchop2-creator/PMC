1

PMC Ads Agent คืออะไร

ระบบหลังบ้านสำหรับดูแลโฆษณา Meta ของคลินิก โดยมี AI เป็นสมองช่วยวิเคราะห์

หน้าที่หลักของระบบ

1. ดึงข้อมูลจริงจาก Meta

ระบบอ่านข้อมูลแคมเปญ ชุดโฆษณา โฆษณา ยอดใช้จ่าย ROAS CTR booking และ metric อื่น ๆ จาก Meta API

2. ให้ AI วิเคราะห์แทนการอ่านตัวเลขเอง

AI จะช่วยสรุปว่าอะไรควรดู อะไรควรทำก่อน และแผนไหนต้องขออนุมัติ

3. คุมการเขียนข้อมูลจริง

ถ้าต้องเปิด/ปิด/แก้ไข/ลบ object ใน Meta ระบบจะแสดงหน้าต่างยืนยันก่อนเสมอ

4. บันทึกความรู้และผลย้อนหลัง

Knowledgebase เก็บ insight, decision, outcome และ learning เพื่อใช้วิเคราะห์รอบต่อไป

Flow การใช้งานรายวัน

ใช้ลำดับนี้ถ้าคุณต้องดูแลโฆษณาทุกวัน

1

เปิดระบบ
เข้า URL ของ PMC Ads Agent และล็อกอินด้วย Basic Auth ที่ทีมกำหนดให้

2

เช็กสถานะ Meta API
ดูปุ่มสีเขียว “เชื่อมต่อ Meta API” หรือแถบแจ้งเตือน ถ้าไม่เขียวให้ไปที่ Settings

3

เลือกช่วงวันที่
เช่น ข้อมูลทั้งหมด, 7 วันล่าสุด, 30 วันล่าสุด, เดือนนี้ หรือไตรมาสนี้

4

ดู Dashboard
อ่านค่าโฆษณา รายได้ ROAS CPA funnel และคำแนะนำภาพรวม

5

เรียก Master Agent
ไปที่ “นักการตลาด AI” แล้วกด “เรียก Master Agent” เพื่อให้ AI วิเคราะห์ข้อมูลล่าสุด

6

อ่านแผนที่ AI เสนอ
ดูเหตุผล หลักฐาน ความเสี่ยง confidence และสิ่งที่ควรทำก่อน

7

อนุมัติหรือถามเจาะลึก
ถ้ายังไม่แน่ใจให้กด “ถามเจาะลึก” ก่อน ถ้าพร้อมให้กด “สร้างแผนอนุมัติ”

8

ดำเนินการตามแผน
ถ้ามีคำสั่ง Meta ชัดเจน ระบบจะแสดงปุ่ม “ดำเนินการใน Meta” ถ้าไม่ชัดจะเป็น checklist เท่านั้น

9

ซิงก์และติดตามผล
หลังดำเนินการ ให้ซิงก์ข้อมูลอีกครั้ง และดู Reports หรือ Phase 4 Learning เพื่อติดตาม outcome

ก่อนกดคำสั่งจริงใน Meta ให้เช็ก 4 อย่าง ชื่อแคมเปญถูกไหม, object type ถูกไหม, สถานะที่จะส่งถูกไหม, และมีแผน rollback หรือหยุดกลับไหม
3

ส่วนประกอบบนหน้าจอ

รู้จักเมนู แถบบน และปุ่มสำคัญก่อนเริ่มใช้งาน

Sidebar / เมนูด้านซ้าย

  • ใช้เปลี่ยนหน้า เช่น วิเคราะห์, ตัวจัดการโฆษณา, นักการตลาด AI
  • บนมือถือให้กดปุ่ม “เมนู” เพื่อเปิดรายการหน้า
  • การ์ดด้านล่างบอกบัญชีโฆษณาและสถานะซิงก์

Topbar / แถบบน

  • แสดงชื่อหน้าปัจจุบัน
  • เลือกช่วงวันที่
  • กดซิงก์ Meta API
  • เลือกโหมด automation
  • กดเตรียมรายงาน

ปุ่ม “เชื่อมต่อ Meta API”

ใช้ดึงข้อมูลล่าสุดจาก Meta ถ้าขึ้นสีเขียวแปลว่าเชื่อมต่อได้ ถ้าขึ้น error ให้ไปหน้า Settings

โหมด Automation

  • แนะนำเท่านั้น: ระบบเสนอแผน แต่ไม่เขียน Meta เอง
  • ต้องอนุมัติก่อน: ใช้กับ flow ที่จะเขียน Meta หลังยืนยัน
  • พัก automation: หยุดการทำงานอัตโนมัติไว้ก่อน
สีของปุ่มและสถานะ เขียว = สถานะดีหรือเปิดใช้งาน, น้ำเงิน = คำสั่งทั่วไปหรือบันทึก, เหลือง = ต้องตรวจ/ต้องอนุมัติ, แดง = เสี่ยงหรือเขียนข้อมูลจริง/ลบจริง
4

คู่มือแต่ละหน้า

ทุกเมนูหลักในระบบ และควรใช้เมื่อไร

1. วิเคราะห์ / Dashboard

ใช้ดูภาพรวมเร็วที่สุดของบัญชีโฆษณา

  • KPI: ค่าโฆษณา รายได้ ROAS CPA Lead Booking
  • Funnel คลินิก: จุดที่ลูกค้าหลุดจาก impression ถึง treatment
  • Campaign table: แคมเปญที่ดี เสี่ยง หรือควรหยุดดู
  • คำแนะนำจากระบบและ audit ล่าสุด

2. ตัวจัดการโฆษณา

ใช้จัดการโครงสร้างจริงจาก Meta: แคมเปญ ชุดโฆษณา และโฆษณา

  • ค้นหา campaign, ad set หรือ ad
  • กดเปิด/ปิดสถานะ object
  • แก้ชื่อหรืองบรายวัน
  • ลบ object ใน Meta เฉพาะกรณีจำเป็นมาก
  • เปิดรีวิวซิงก์เพื่อตรวจข้อมูลว่าพร้อมหรือไม่

3. นักการตลาด AI

หน้าหลักของ PMC Master Agent ใช้ให้ AI อ่านข้อมูลและสรุปแผน

  • กด “เรียก Master Agent”
  • ดูสรุปจาก AI เป็นภาษาคน
  • ดูสิ่งที่ควรดูตอนนี้และสิ่งที่ควรทำก่อน
  • กด “ถามเจาะลึก” เพื่อถามแผนนั้นละเอียดขึ้น
  • กด “สร้างแผนอนุมัติ” เพื่อเริ่ม flow อนุมัติ

4. Optimizer & Automation

ใช้กรองรายการที่ควรเปิด/ปิด/คุมงบตาม metric จริง

  • เลือกกลยุทธ์ เช่น เปิดกลับ, ปิดลดรั่ว, ดูทั้งหมด
  • ดู Decision Board และรายการเข้าเกณฑ์
  • รัน batch ได้เมื่ออยู่ในโหมดที่ต้องอนุมัติก่อน
  • สร้างกฎ custom เช่น Budget, Pause, Schedule, Creative

5. สตูดิโอครีเอทีฟ

ใช้ดูผลงานครีเอทีฟจาก ads และ insight ที่ซิงก์มา

  • ดู creative ที่ชนะหรือควรรีเฟรช
  • ดู spend, CTR, results, ROAS ตาม creative
  • ใช้เป็นข้อมูลให้ทีมครีเอทีฟผลิตงานใหม่

6. กลุ่มเป้าหมาย

ใช้ดู segment และ audience จาก ad set จริง

  • ดู audience ที่ใช้เงินเยอะหรือได้ booking ดี
  • ดู placement และ targeting โดยรวม
  • ช่วยตัดสินใจว่าจะ scale หรือเปลี่ยนกลุ่มเป้าหมาย

7. คลังโฆษณา

ใช้ดู asset และความเสี่ยง compliance ก่อน launch

  • ดูรายการที่ approved, needs review หรือ blocked
  • ตรวจ claim ทางการแพทย์
  • ใช้เป็นด่านก่อนเปิดโฆษณาใหม่

8. รายงาน

ใช้เตรียมรายงานและรัน Phase 4 Learning & Monitoring

  • สร้างรายงานจากข้อมูลล่าสุด
  • ดู outcome observations
  • ดู learning records และ monitoring alerts
  • ใช้สรุปงานให้ทีมทุกวันหรือทุกสัปดาห์

9. ตั้งค่า

ใช้ตั้งค่า Meta API และตรวจสถานะเชื่อมต่อ

  • ใส่ Access Token และ Ad Account ID
  • เลือก Graph Version, Date Preset, Max Pages
  • กด Save & Test เพื่อบันทึกและตรวจเชื่อมต่อ

10. ศูนย์ช่วยเหลือ

ใช้ดู playbook การรีวิวโฆษณารายวัน

  • แนวทางเช็กข้อมูลก่อนตัดสินใจ
  • ปุ่มไป Settings หรือ Sync ใหม่
  • เหมาะสำหรับผู้ใช้งานใหม่

Flow การใช้ AI Master Agent

ใช้เมื่อต้องการให้ AI เป็นสมองช่วยอ่านข้อมูลและเสนอแผน

กดเรียก Master AgentAI อ่าน WorkspaceData, Website Context, Memory
AI แบ่งงานให้ AgentCampaign, Budget, Funnel, Creative, Audience, Compliance
สรุปคำแนะนำแสดงสิ่งที่ควรดูและสิ่งที่ควรทำก่อน
ถามเจาะลึกหรือสร้างแผนผู้ใช้เลือกทางที่ต้องการ

อ่านผล AI อย่างไร

ช่องข้อมูลวิธีอ่าน
สรุปจาก Master Agentอ่านเหมือนผู้จัดการสรุปให้ฟังว่าภาพรวมควรสนใจอะไร
สิ่งที่ควรดูตอนนี้ปัญหา สัญญาณผิดปกติ หรือโอกาสที่ควรตรวจ
สิ่งที่ควรทำก่อนแผนที่ AI เสนอให้ขออนุมัติหรือทำต่อ
ความเสี่ยงต่ำ/กลาง/สูง ยิ่งสูงยิ่งต้องอ่านละเอียดก่อนกด
ConfidenceAI มั่นใจแค่ไหนจากข้อมูลที่มี ไม่ใช่การรับประกันผลลัพธ์
หลักฐานตัวเลขหรือข้อมูลจริงที่ AI ใช้คิด เช่น spend, ROAS, CPA
ถ้าผล AI ดูแปลก ให้กดซิงก์ Meta อีกครั้ง แล้วเรียก Master Agent ใหม่ ถ้ายังแปลกให้ตรวจช่วงวันที่และข้อมูลใน Settings

การอนุมัติแผนและการเขียน Meta จริง

ส่วนนี้สำคัญที่สุด เพราะเกี่ยวข้องกับการเปลี่ยนโฆษณาจริง

AI เสนอ Actionเช่น เปิดกลับแบบค่อยเป็นค่อยไป หรือคงพักไว้
ผู้ใช้กดสร้างแผนระบบเปิดหน้าต่างอนุมัติ
ระบบแยกประเภทMeta action หรือ checklist
ผู้ใช้ยืนยันจึงเริ่มทำตามแผน

แบบที่ 1: Checklist เท่านั้น

ใช้กับงานตรวจสอบ วิเคราะห์ tracking compliance creative หรือ diagnosis ที่ยังไม่มีคำสั่งเปิด/ปิดชัดเจน

  • ระบบจะไม่เดาเอง
  • ไม่เขียนข้อมูลไป Meta
  • ผู้ใช้ทำตามรายการ แล้วกดบันทึกว่าเสร็จ

แบบที่ 2: ดำเนินการใน Meta

ใช้เมื่อระบบรู้ชัดว่า object ไหนและต้องส่งสถานะอะไร เช่น เปิดใช้งานหรือหยุดใช้งาน

  • แสดง Action ใน Meta
  • แสดง Meta object และ ID
  • แสดงคำสั่งที่จะส่ง
  • ผู้ใช้ต้องกด “ดำเนินการใน Meta” อีกครั้ง
ปุ่มที่ต้องระวัง ดำเนินการใน Meta, ยืนยันใน Meta, ลบใน Meta คือปุ่มที่อาจเปลี่ยนข้อมูลจริง อย่ากดถ้ายังไม่มั่นใจชื่อแคมเปญและคำสั่งที่จะส่ง

ตัวอย่างการอ่านหน้าต่างดำเนินการแผน

ช่องต้องเช็กอะไร
แผนอ่านว่า AI ต้องการให้ทำอะไร เช่น เปิดกลับแบบจำกัดงบ หรือพักไว้ก่อน
Action ใน Metaดูว่าระบบจะเปิด/พัก object อะไร
Meta objectดูว่าเป็นแคมเปญ ชุดโฆษณา หรือโฆษณา และ ID ถูกต้องไหม
คำสั่งที่จะส่งต้องตรงกับที่ต้องการ เช่น “เปิดใช้งาน” หรือ “หยุดใช้งาน”
เกณฑ์ควบคุมอ่านว่าถ้าผลแย่ลงต้องหยุดหรือ rollback อย่างไร
7

ระบบไม่ได้แค่วิเคราะห์รอบเดียว แต่เก็บข้อมูลไว้ใช้คิดในอนาคต

Outcome Observation

สัญญาณเตือน เช่น ไม่มี active campaign, ข้อมูล stale, หรือแผนเสี่ยงสูงค้างอนุมัติ

สำคัญ Learning เป็นการอ่านความสัมพันธ์จากข้อมูล ไม่ใช่การยืนยันสาเหตุ 100% ผู้ใช้ยังต้องตรวจบริบทจริงของแคมเปญเสมอ
8

การตั้งค่าและการเชื่อมต่อ Meta

ใช้เมื่อระบบยังไม่เห็นข้อมูล หรือ Meta API ต่อไม่ติด

1

ไปที่หน้า “ตั้งค่า”
อยู่ในกลุ่มเมนูระบบด้านซ้าย หรือกดจากศูนย์ช่วยเหลือ

2

ใส่ Access Token
ใช้ token ที่มีสิทธิ์อ่านโฆษณา เช่น ads_read และถ้าต้องเขียนข้อมูลต้องมีสิทธิ์ที่เหมาะสม

3

ใส่ Ad Account ID
ควรอยู่ในรูปแบบของบัญชีโฆษณา เช่น act_... หรือเลขบัญชีตามที่ระบบรองรับ

4

เลือกค่าอื่น
Graph Version, Date Preset, Max Pages

5

กด Save & Test
ระบบจะบันทึกและตรวจเชื่อมต่อ ถ้าผ่านให้กลับไปกดซิงก์ Meta API

ห้ามแชร์ Token ในแชตหรือเอกสารทั่วไป Token คือกุญแจเข้าบัญชีโฆษณา ควรส่งผ่านช่องทางปลอดภัยและให้เฉพาะคนที่รับผิดชอบ
อาการสิ่งที่ควรทำ
ขึ้น “ต้องตั้งค่าก่อน”ไปหน้า Settings แล้วใส่ Token และ Ad Account ID
ขึ้น “ซิงก์ผิดพลาด”Token อาจหมดอายุ, ไม่มี permission, หรือ account ไม่ถูกต้อง
เชื่อมต่อได้แต่ไม่มีข้อมูลลองเปลี่ยนช่วงวันที่เป็น “ข้อมูลทั้งหมด” หรือ “30 วันล่าสุด”
AI ตอบช้ารอสักครู่ หรือซิงก์ใหม่แล้วเรียก Master Agent อีกครั้ง
9

คู่มือสำหรับมือถือ

ระบบรองรับมือถือ แต่บางงานที่เสี่ยงควรทำบนจอใหญ่เพื่ออ่านรายละเอียดครบ

เปิดเมนู

บนมือถือ ให้กดปุ่ม “เมนู” ที่มุมบนขวาของแถบโลโก้ เพื่อเลือกหน้าอื่น

อ่านการ์ดโฆษณา

การ์ดจะแสดงชื่อ object, สถานะ, spend, ROAS และปุ่มคำสั่งในแนวตั้งเพื่อไม่ให้ล้นจอ

หน้าต่างยืนยัน

Modal จะแสดงเป็นแผ่นด้านล่าง อ่านให้ครบก่อนกดปุ่มสีน้ำเงินหรือแดง

งานที่ควรทำบนคอมพิวเตอร์

การลบ object, batch optimizer, หรือการตรวจรายละเอียดหลายแคมเปญ ควรทำบนจอใหญ่

ตรวจแล้ว Layout หลักรองรับมือถือขนาดประมาณ 360-390px โดยไม่มีการล้นแนวนอนในเมนูหลัก
10

คำถามที่พบบ่อย

คำตอบสั้น ๆ สำหรับปัญหาที่เจอบ่อย

1. กดซิงก์แล้วข้อมูลไม่มา

ตรวจ Settings, Token, Ad Account ID และลองเปลี่ยนช่วงวันที่เป็น “ข้อมูลทั้งหมด”

2. AI บอกให้เปิดแคมเปญ ต้องกดเลยไหม

ไม่ต้องรีบ กด “ถามเจาะลึก” ก่อน แล้วอ่านหลักฐานและเกณฑ์ควบคุมให้ครบ

3. อนุมัติเป็นแผนแล้วเกิดอะไรต่อ

ระบบจะเปิด flow ดำเนินการต่อ ถ้าแผนส่ง Meta ได้จะมีปุ่ม “ดำเนินการใน Meta” ถ้าไม่ชัดจะเป็น checklist

4. กดผิดแล้วทำอย่างไร

รีบซิงก์ข้อมูลใหม่ ตรวจสถานะใน Ads Manager และใช้ rollback ตาม guardrail หรือเปิด Meta Ads Manager ตรวจซ้ำ

5. ทำไมบางแผนไม่มีปุ่มส่ง Meta

เพราะแผนนั้นเป็นงานตรวจสอบ เช่น tracking, creative, compliance หรือ diagnosis ระบบจึงไม่เดาคำสั่งเอง

6. รายงานใช้ทำอะไร

ใช้สรุป performance, outcome, learning, alert และ next actions สำหรับทีม

เช็กลิสต์ก่อนจบงานประจำวัน ซิงก์ข้อมูลล่าสุดแล้ว, อ่าน Dashboard แล้ว, เรียก Master Agent แล้ว, ตรวจแผนที่ค้างอนุมัติแล้ว, บันทึกผลหรือรายงานแล้ว

เอกสารนี้สร้างจากโครงระบบ PMC Ads Agent ในโปรเจกต์ปัจจุบัน และไม่รวมรหัสผ่าน, token หรือข้อมูลลับของบัญชีโฆษณา
