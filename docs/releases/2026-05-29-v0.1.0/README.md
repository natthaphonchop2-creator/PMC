This release organizes the latest Page Automation and Home launcher work into one release folder, records the current project version, and establishes the permanent project update log.

## Development Rule

Any later change to this project must update `docs/PROJECT_UPDATES.md` before stage or commit. If a later release adds previews, PDFs, screenshots, or visual assets, create a new `docs/releases/<date>-v<version>/` folder and add a README index there.
