PMC Ads Agent คู่มือฉบับสั้นสำหรับ Toolbar

คู่มือ Toolbar
PMC Ads Agent

เอกสารนี้อธิบายเฉพาะปุ่มและแถบเครื่องมือที่เห็นบนหน้าจอ: เมนูด้านซ้าย, แถบบน, ปุ่มซิงก์ Meta API, ตัวกรองวันที่, โหมด Automation และปุ่มรายงาน พร้อมภาพประกอบจากระบบจริง

Sidebar ด้านซ้าย Topbar ด้านบน ปุ่มที่ควรระวัง

ภาพรวมจากหน้าเว็บจริง: ด้านซ้ายคือเมนูหลัก ด้านบนคือแถบควบคุมข้อมูลและการทำงาน

1. ภาพรวม Toolbar ที่มีในระบบ

Toolbar ของระบบแบ่งเป็น 2 ส่วนหลัก อ่านแบบง่ายคือ “ซ้ายไว้เปลี่ยนหน้า” และ “ด้านบนไว้ควบคุมข้อมูลปัจจุบัน”

Sidebar ด้านซ้าย

ใช้ย้ายไปหน้าต่าง ๆ ของระบบ เช่น วิเคราะห์, ตัวจัดการโฆษณา, นักการตลาด AI, รายงาน และตั้งค่า

ปุ่มที่มีพื้นหลังสีม่วงคือหน้าที่กำลังเปิดอยู่ตอนนี้

Topbar ด้านบน

ใช้ดูชื่อหน้าปัจจุบัน เลือกบัญชี/ช่วงวันที่ ซิงก์ข้อมูล Meta API เลือกโหมด Automation และเตรียมรายงาน

ถ้าข้อมูลไม่อัปเดต ให้เริ่มจากปุ่ม “เชื่อมต่อ Meta API”

จำให้สั้นที่สุด: เมนูซ้าย = เลือกงานที่จะทำ, แถบบน = เลือกข้อมูลและสั่งให้ระบบอัปเดต
ข้อควรระวัง: Toolbar ส่วนใหญ่เป็นปุ่มดูข้อมูลและเปลี่ยนหน้า แต่ถ้าเข้าไปกดคำสั่งในหน้าต่างยืนยัน เช่น เปิด/ปิด/ลบใน Meta ให้ตรวจชื่อแคมเปญและคำสั่งก่อนเสมอ

2. Sidebar ด้านซ้าย

แถบนี้ใช้เปลี่ยนหน้าในระบบ เป็นทางลัดหลักของผู้ใช้งาน

ปุ่ม ใช้ทำอะไร
1โลโก้ PMC บอกว่าคุณอยู่ในระบบ PMC Ads Agent
2วิเคราะห์ เปิด Dashboard เพื่อดูภาพรวมตัวเลขหลัก เช่น spend, revenue, ROAS, CPA และ funnel
3ตัวจัดการโฆษณา ดูและจัดการ Campaign, Ad set และ Ad จากข้อมูล Meta จริง
4นักการตลาด AI เรียก Master Agent ให้สรุปข้อมูลและเสนอแผนที่ควรทำต่อ
5Optimizer & Automation ดูแผนเพิ่มประสิทธิภาพ เช่น แนะนำเปิดกลับ, หยุดรั่ว, คุมงบ หรือ batch action
6สตูดิโอครีเอทีฟ ดู creative และ insight ที่เกี่ยวกับงานโฆษณา เพื่อช่วยตัดสินใจรีเฟรชครีเอทีฟ
7กลุ่มเป้าหมาย ดู segment, audience, placement และสัญญาณจาก ad set
8คลังโฆษณา ดู asset และความพร้อมด้าน compliance ก่อนใช้งานจริง
9รายงาน เตรียมรายงาน สรุป outcome และดู learning/monitoring ของระบบ
10ตั้งค่า ตั้งค่า Meta API, token, ad account และตรวจสถานะการเชื่อมต่อ
11ช่วยเหลือ เปิดคู่มือหรือ playbook สั้น ๆ เมื่อไม่แน่ใจว่าควรเริ่มจากตรงไหน
วิธีดูหน้าปัจจุบัน: ไอคอนที่มีพื้นหลังสีม่วงคือหน้าที่คุณกำลังใช้งานอยู่

3. Topbar ด้านบน

แถบบนคือจุดควบคุมข้อมูลที่กำลังดูอยู่ในหน้านั้น

ส่วนบนหน้าจอ คำอธิบายแบบง่าย ควรกดเมื่อไร
1ชื่อหน้า บอกว่าตอนนี้อยู่หน้าอะไร เช่น ตัวจัดการโฆษณา, นักการตลาด AI หรือรายงาน ใช้เช็กว่าคุณอยู่ถูกหน้าก่อนทำงาน
2บัญชี Workspace แสดงบัญชีหรือ workspace ที่กำลังใช้ เช่น Promed Clinic PMC ดูให้แน่ใจก่อนอ่านตัวเลขหรือส่งคำสั่ง
3ช่วงวันที่ เลือกข้อมูลที่ต้องการดู เช่น ข้อมูลทั้งหมด, 7 วันล่าสุด, 30 วันล่าสุด, เดือนนี้ เมื่ออยากดูตัวเลขในช่วงเวลาอื่น
4เชื่อมต่อ Meta API ดึงข้อมูลล่าสุดจาก Meta เข้ามาในระบบ ถ้าสีเขียวคือเชื่อมต่อได้ กดก่อนเริ่มงาน หรือเมื่อข้อมูลดูไม่อัปเดต
5โหมด Automation กำหนดระดับการทำงาน เช่น แนะนำเท่านั้น หรือ ต้องอนุมัติก่อน ตั้งก่อนใช้ AI/Optimizer ที่เกี่ยวกับ action จริง
6เตรียมรายงาน สร้างสรุปสำหรับส่งต่อหรือรีวิวกับทีมจากข้อมูลล่าสุด ใช้ท้ายวันหรือก่อนประชุม
ถ้าข้อมูลดูผิด: ให้เช็ก 3 อย่างตามลำดับ: ช่วงวันที่ถูกไหม, กดเชื่อมต่อ Meta API แล้วหรือยัง, และบัญชี Workspace ถูกต้องไหม

4. ใช้ Toolbar บนมือถือ

บนมือถือ ระบบจะจัดปุ่มให้แคบลงเพื่อไม่ให้ล้นจอ หลักการใช้งานยังเหมือนเดิม

เมนูด้านซ้าย

ถ้าหน้าจอเล็ก ให้กดปุ่มเมนูเพื่อเปิดรายการหน้า แล้วเลือกหน้าที่ต้องการใช้งาน

แถบบน

ปุ่มอาจเรียงลงหลายบรรทัด ให้ดูจากชื่อปุ่มเป็นหลัก เช่น ช่วงวันที่, เชื่อมต่อ Meta API, เตรียมรายงาน

ก่อนกดคำสั่งสำคัญ

บนมือถืออ่านข้อความยืนยันให้ครบ เพราะพื้นที่แคบและมีโอกาสกดผิดง่ายกว่าจอคอมพิวเตอร์

งานที่ควรทำบนจอใหญ่

งานลบ, batch action, หรือดำเนินการใน Meta จริง ควรทำบนคอมพิวเตอร์เพื่อเห็นรายละเอียดครบ

สูตรใช้งานเร็ว: 1) เปิดหน้าจาก Sidebar 2) เลือกช่วงวันที่จาก Topbar 3) กดเชื่อมต่อ Meta API 4) เริ่มอ่านข้อมูลหรือให้ AI วิเคราะห์
